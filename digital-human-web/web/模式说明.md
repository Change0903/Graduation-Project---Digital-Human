# 数字人项目模式说明

## 项目结构
- 后端目录：`E:\PycharmDemo\Deepseek`
- 前端目录：`E:\PycharmDemo\Deepseek\digital-human-web\web`

## 模式一：视频模式（完整数字人）
- 后端入口：`server.py`
- 前端页面：`index.html`
- 前端脚本：`main.js`
- WebSocket：`ws://localhost:9999`

特点：
- 会生成音频和视频
- 响应时间较长（需要 Wav2Lip 推理）

启动方式：
```bash
cd E:\PycharmDemo\Deepseek
python server.py
```

## 模式二：语音模式（快速）
- 后端入口：`server-2.py`
- 前端页面：`index-2.html`（或你当前正在使用的页面）
- 前端脚本：`main-2.js`（或对应脚本）
- WebSocket：`ws://localhost:9998`

特点：
- 只生成音频，不生成视频
- 响应更快，适合调试和联调

启动方式：
```bash
cd E:\PycharmDemo\Deepseek
python server-2.py
```

## 使用建议
- 先用语音模式验证接口和对话流程
- 再切换到视频模式验证数字人口型效果
